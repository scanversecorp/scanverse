## Daily workflow

1. `node scripts/social_pulse.mjs` — see today's caption + checklist
2. Open `#admin?tab=social` — **Post everywhere today** panel
3. Copy caption once → paste on all 5 platforms
4. For video days: record once → upload as Reel + Short + TikTok
5. Mark each platform ✓ in dashboard (saves URL + timestamp)
6. When 5/5 done → day counts toward streak
